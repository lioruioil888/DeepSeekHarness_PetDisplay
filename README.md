# DeepSeekHarness_PetDisplay
适合新手小白的创建deepseek桌宠教程-看了不烧心版
十分简单，下载安装5步曲
1.在浏览器上下载一个适配你的操作系统的deepseekharness，正常登录，新人赠送6元token，完全够用
2.在deepseek官网找到deepseekAPI，创建一个自己的APIkey，记得要保存好APIkey
3.然后就可以在deepseekharness上直接让你的ai帮你下载，第一条prompt（这个是装桌宠）：帮我安装这个插件:github.com/MerZlin/dsh-pet-indesktop
4.第二步（装开机动画）：帮我装这个插件:NativeDog1/dsh-boot-animation
5.第三步（装打开dsh的主题界面）：在插件中下载个dshmarket，将插件可视化，再下载dsh-plugin-wallpaper-engine这个插件，就可以在wallpaper选中自己喜欢的壁纸当主题界面了
注：如果大肥鱼没有舞狮等动作，直接和deepseek说装动作素材就可以
